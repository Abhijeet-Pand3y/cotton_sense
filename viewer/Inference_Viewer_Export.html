Load an inference run

Pick a folder of original (un-annotated) frames, then a folder of per-frame JSON detections (the output of infer_v3.py --save-json).

If both are in the same folder, just pick it once with "Load frames".

Optionally add RealSense depth: pick the depth/ folder of .npy maps with "Load depth" — or simply pick the whole run folder once (frames + detections + depth + metadata.json all load together).

Tested on Chrome / Edge. Supports drag-and-drop too — drop a folder anywhere on this window.
