# Depth analysis — GX010120_test (no tape on the ball)

8 frames, 1 ball, never occluded. Source video `GX010120.MP4`; frames extracted
with the same recipe as every other set (`crop=4780:2988:0:0`, `-q:v 2`).

This set is not measurable by `analyse_ball_sets.py`. That script needs a tape
distance for every ball, and here the ball's distance was never recorded. What
was recorded is the *bottle's* distance — 5, 11, 15, 19, 25, 29 in — while the
ball sat untouched on its stand. So this is the "nothing of known size in the
picture" case in full: every constant comes from other recordings, and the frame
contributes nothing but pixels.

Produced by `scripts/depth/analyse_noref_set.py --set frames/GX010120_test`.
Per-frame numbers in `frames/GX010120_test/noref_analysis.csv`.

## 1b. Geometry check — distance from ball size alone (no DA3)

The ball's pixel radius varies by only **1.38%** across the whole clip, so the
pinhole relation pins its distance tightly without any depth model:

| | value |
|---|---|
| distance from pixel size | **497.8 ± 2.7 mm (19.60 in)** |
| DA3, no reference | 588.4 mm, range 533.3–652.0 mm |
| DA3 vs geometry | **+18.2%**, range +6.6% to +30.7%, all eight positive |

The ball's distance was never tape-measured, so **this is a cross-check, not an
accuracy score** — geometry and DA3 disagree by 18% and geometry is the steadier
of the two, but nothing here proves which is right. It does place the ball at
roughly 19–20 in, which is where the rest of the ladder sits.

Note that the size error and the distance error are the same measurement told
twice: size is `2·r·Z/f`, so an 18% distance over-estimate on a stable radius
*is* the 11% size over-estimate. They are not independent evidence.

## 2. Compared with base

Two frames hold the ball alone; six hold the ball with the bottle at a known
distance. The ball is identical in all eight, so any difference is the bottle's.

| | measured size |
|---|---|
| ball alone (n=2) | 42.86 mm |
| bottle present (n=6) | 44.96 ± 3.41 mm |
| difference | **+2.10 mm** |

**The bottle's effect is not detectable above the noise.** The two ball-alone
frames — one second apart, nothing whatever changed between them — already
differ by **2.74 mm**, more than the entire base-to-bottle shift. And the
bottle's distance does not predict the error: fitting size against bottle
distance over the six frames gives r² = 0.07 (n = 6), i.e. nothing.

What *is* large is the frame-to-frame scatter itself. On a ball that never moved,
DA3's output swings **14.7%** and the measured size spans **40.1–49.1 mm — 22.6%
of the true size**. Since the pixel radius holds to 1.38%, all of that enters
through depth.

## 3. Compared with the established no-reference baseline

| | n | mean size error | in mm |
|---|---|---|---|
| existing study, nothing of known size | 116 | 16.99% | 6.80 |
| **GX010120_test (new data)** | **8** | **11.08%** | **4.43** |

Welch t = −2.03, df ≈ 8.6, **p = 0.07**. The new recording is **not worse, and
not proven better** — the confidence intervals overlap.

The difference that does stand out is in sign, not size. The existing baseline is
roughly unbiased (signed mean −2.09%, 54% of errors positive); this set is
**100% positive, signed mean +11.08%**. A one-directional error is the signature
of a scale constant that does not transfer: `a` was fitted on other recordings
and is simply wrong for this scene, which is the same conclusion the team
document already draws from the cotton footage.

## 4. What this set cannot say

- **No distance accuracy.** No tape on the ball, so no ground truth. Section 1b
  is a consistency check between two estimators, not an error measurement.
- **One distance only.** Every frame views the ball from ~19.6 in, so nothing
  here speaks to how the error varies with distance.
- **n = 8, one ball, one scene.** The comparison in section 3 rests on eight
  correlated frames of a single object.
- **The bottle is never measured.** It is a distractor at a known distance, not a
  measurement target; it is too dark against the drape to segment reliably, and
  no attempt to measure it is reported here.
